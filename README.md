# ChibiNanny

Пшик, чиби в наушниках, живёт на рабочем столе Windows, берёт задачи из [Tasks](https://occasionalddd100.github.io/tasks/) (тот же Supabase и аккаунт) и пинает их делать.

## Что умеет
- Ходит и прыгает по панели задач, его можно схватить мышкой и бросить.
- Утром предлагает 3 главные задачи: просроченные, на сегодня, 🔥, «Ближайшее». Выбрал задачу, и пошёл фокус на 25 минут: Пшик сидит рядом в наушниках.
- По таймеру спрашивает: Сделал / Ещё / Застрял / Перерыв. «Сделал» отмечает задачу в Tasks. «Застрял» просит самый маленький шаг и заводит его подзадачей на 10 минут.
- Если ты без задачи, пинает раз в 20 минут. Если молчишь, через 10 минут злится и пищит, через 20 садится большим посреди экрана.
- Кнопка «Мне тяжело» включает мягкий режим до конца дня: без эскалации, задачи на 10 минут.
- Вечером подводит итог, считает серию дней.
- Чат через любой OpenAI-совместимый API. По умолчанию это бесплатные модели OpenRouter, ключ берётся на openrouter.ai/keys. Для Ollama укажи адрес `http://localhost:11434/v1`, ключ не нужен (может понадобиться `OLLAMA_ORIGINS=*`). В модель уходят только названия задач.
- Клик или ПКМ по Пшику открывает меню. В трее есть «Позвать Пшика» и «Выйти». В ⚙ настраиваются тон (мягко / нормально / по жопе), размер, тайминги, тихие часы и автозапуск.

## Установка
Скачай `ChibiNanny-setup.exe` из [Releases](../../releases/latest) и запусти. Сборка идёт сама при каждом пуше в main (GitHub Actions, `windows.yml`).

## Разработка
```
npm install
npm run dev          # превью в браузере, окно не двигается
npx tauri dev        # настоящее окно (нужны Rust и WebView2)
```
